# Shared-storage wire-format fixture

These are SQLite databases with `.bin` extensions so they cannot be confused
with production office resources in bundle checks. The native test copies them
to `fixture.sqlite` and `office-resources.sqlite` in a temporary directory.

They were generated by `compileCorpus` and `packSharedCorpora` from
`Tools/ContentCompiler/Fixtures/evening-pilot.json`. Before compilation, the
fixture's coverage records its actual authoritative-office count, and its
legacy Vespers and Compline documents receive the fixture day's observance
with `eveningContext: "ferialVespers"`. This supplies the metadata required by
the current validator without changing any prayer or chant. The fixture is a
codec/integration test, not a reviewed liturgical release.

Regenerate with Node 24 from the repository root:

```sh
node --input-type=module <<'JS'
import { mkdirSync, copyFileSync } from 'node:fs';
import { compileCorpus, loadCorpus } from './Tools/ContentCompiler/Sources/compiler.ts';
import { packSharedCorpora } from './Tools/ContentCompiler/Sources/sharedCorpus.ts';
const directory = '.build/shared-native-fixture';
mkdirSync(directory, { recursive: true });
const corpus = loadCorpus('Tools/ContentCompiler/Fixtures/evening-pilot.json');
corpus.manifest.coverage.authoritativeOfficeCount = corpus.offices.filter(o => o.format === 'authoritativeOrdered').length;
for (const office of corpus.offices) {
  if (office.hour === 'vespers' || office.hour === 'compline') {
    office.observance = { ...corpus.days[0], ...office.observance, eveningContext: 'ferialVespers' };
  }
}
compileCorpus(corpus, `${directory}/fixture.sqlite`, true);
packSharedCorpora([`${directory}/fixture.sqlite`], `${directory}/packed`);
copyFileSync(`${directory}/packed/fixture.sqlite`, 'HoursTests/Fixtures/SharedStorage/shared-edition-fixture.bin');
copyFileSync(`${directory}/packed/office-resources.sqlite`, 'HoursTests/Fixtures/SharedStorage/shared-catalog-fixture.bin');
JS
```
